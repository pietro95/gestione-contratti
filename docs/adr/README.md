# Decision record architetturali

Gli ADR documentano decisioni tecniche durature, il contesto in cui sono state prese e le conseguenze. Non sostituiscono la SPEC funzionale né la cronologia della ROADMAP.

## Formato

Ogni file usa il nome `NNNN-titolo-breve.md` e contiene:

- stato: proposto, accettato, sostituito o ritirato;
- data;
- contesto;
- decisione;
- conseguenze;
- eventuale ADR sostitutivo.

Gli ADR accettati non vengono riscritti per riflettere il presente: una decisione nuova sostituisce quella precedente con un nuovo documento.
